=======================================================
AI SMART FOOD WASTE & DONATION SYSTEM - SETUP GUIDE
=======================================================

1. Extract this ZIP file into a folder on your laptop.
2. Open Command Prompt (CMD) or Terminal inside that folder.
3. Install required packages by running:
   pip install -r requirements.txt
4. Run the application using:
   streamlit run app.py
5. To convert into an APK / Web App:
   - Upload these files to GitHub and deploy on Streamlit Cloud (share.streamlit.io).
   - Take the generated website URL and convert it to an APK using WebIntoApp / AppsGeyser / PWABuilder.
